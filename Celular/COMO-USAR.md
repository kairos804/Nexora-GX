# Nexora GX — Versão para Celular

## Como usar pelo site

Abra a página da versão Mobile no navegador do celular. Não é necessário instalar APK.

## Como usar pelos arquivos

1. Baixe a pasta/arquivo da versão Mobile.
2. Abra `index.html` no navegador compatível.
3. Use a interface diretamente pelo celular.

A versão Mobile foi feita para toque, telas pequenas e uso pelo navegador.

> Observação: a interface da Nexora AI pode ser aberta, mas respostas de IA exigem que o backend `/api/ai` esteja hospedado e configurado com as credenciais dos provedores.
