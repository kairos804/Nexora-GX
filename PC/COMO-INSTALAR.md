# Nexora GX — Versão para PC

## Como instalar

1. Baixe o instalador `.exe` gerado pelo Nexora GX.
2. Execute o instalador no Windows.
3. Escolha a pasta de instalação.
4. Clique em **Instalar**.
5. Abra o **Nexora GX** pelo atalho criado.

## Requisitos

- Windows 10 ou superior.
- Arquitetura x64.

A versão para PC usa Electron e mantém o Nexora GX como aplicativo de desktop.
