# Nexora GX

Um navegador poderoso anônimo.

**Versão 1.2.2**

## Inclui
- Pesquisa integrada
- Relógio em tempo real
- Calculadora
- Chat Nexora Connect
- Aplicativo desktop com Electron
- Chromium via Electron
- Build para Windows (`.exe`) com Electron Builder

## Rodar no PC

```bash
npm install
npm start
```

## Gerar instalador `.exe`

```bash
npm run build:win
```

O instalador Windows será gerado na pasta `dist/`.
