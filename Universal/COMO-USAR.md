# Nexora GX — Versão Universal

A versão Universal é a opção para quem quer acessar o Nexora GX sem depender de um instalador específico.

## Como usar

- Pelo navegador: abra a versão web hospedada do Nexora GX.
- Pelos arquivos: abra a página HTML da versão correspondente.
- No computador, use a versão PC quando quiser o aplicativo Electron.
- No celular, use a versão Mobile para uma interface adaptada a toque.

## Importante sobre a Nexora AI

O frontend da IA está integrado às interfaces, mas as respostas dependem do backend `/api/ai` e das credenciais dos provedores. Chaves de API não devem ser colocadas em arquivos HTML públicos.
