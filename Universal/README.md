# Nexora GX Universal

Área de orientação para acessar o Nexora GX em diferentes formatos.

- **PC:** aplicativo Electron para Windows.
- **Celular:** versão web/mobile que pode ser hospedada ou aberta pelos arquivos.
- **Universal:** acesso pelo navegador e orientações para escolher a versão adequada.

Consulte `COMO-USAR.md` para as instruções gerais.
